# Tutorial 2: working with AI and testing code

Open this folder in VS Code. You only need beginner Python for input, output and conditions.

1. Open `requirements.md` and read the project goal.
2. Attach the file to VS Code Chat with Add Context or a selected file mention.
3. Ask AI to identify ambiguities and ask one question at a time. Do not request code yet.
4. Answer from the tutor's rule card. Review the wording and update the file.
5. Explain the requirements to your partner and complete the review checkpoint.
6. Add tests to `test_plan.csv`. Work out Expected and Purpose before execution.
7. Ask AI to critique missing cases. Review its suggestions yourself.
8. Request a plan, review it, then implement `result_checker.py` with AI.
9. Run the program for every test. Enter coursework first, then exam, on separate lines.
10. Record Actual and Verdict. Report a mismatch using the relevant requirement.
11. Review any repair and rerun the full test set.

In a terminal opened in this folder, run `python result_checker.py` on Windows, or
`python3 result_checker.py` if your system uses that command. Run it again for each input pair.

For the independent activity, change only the exam minimum to 45. Review the changed
requirement and expected tests before asking AI to change the code.

Follow the assignment rubric for the evidence to submit. This folder is a class exercise.
